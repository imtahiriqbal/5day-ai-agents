# 5-Day AI Agents
Implementation of 5-Day AI Agents Intensive Course with Google x Kaggle

## Setup

1. Create a virtual environment:
   ```bash
   python3 -m venv venv
   ```

2. Activate the virtual environment:
   - On Windows: `venv\Scripts\activate`
   - On macOS/Linux: `source venv/bin/activate`

3. Set up environment variables:
   Copy the `.env.example` file to `.env` and fill in your actual API keys and other environment variables.
   ```bash
   cp .env.example .env
   ```
   Then edit `.env` with your actual values.

4. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

5. Run Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
   This will open Jupyter in your browser, where you can navigate to the directory and open the `.ipynb` files.
